# ckman web

React UI for the get-encatch fork of ckman. See [`../FORK.md`](../FORK.md) for
how it is built, how to run it against a ckman backend, and how the API works.

Stack: React 19, Vite, TypeScript, Tailwind CSS 4, shadcn/ui (Base UI,
`base-nova` style), TanStack Router, Query and Table.

Add shadcn components with `npx shadcn@latest add <name>`.
